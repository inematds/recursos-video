# 🎬 Video Resources — INEMA ecosystem

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

Catalog and guide to all projects in the INEMA ecosystem that **generate or process video**,
organized by category, with what each one does, how to run it, and the repository link.

Single-page self-contained (`index.html`, INEMA dark/amber style) — opens via `file://`
or publishes directly to GitHub Pages.

## Categories

- **A · Deterministic rendering** — pixflow, inemaref, HyperFrames, Remotion, mcp-video
- **B · AI generation** — VideosDGX2 (Wan 2.2), HuMo, skyreelsv3, Open-Generative-AI, seedance2
- **C · Direction, storyboard & prompt** — mdd, diretor-animacao, video-plan-editor, promptprof, fontefilm
- **D · End-to-end orchestrators** — skill-videoprodutor, video-explicativo, video-demonstrativo, videos-cursos-inema, mkivideos, timesmkt3
- **E · Support (voice & image)** — inemavox, inemavox2, chatterbox, inemaimg, Kokoro
- **F · Dubbing & post-production** — dublar5, video-use, upscayl

## View

Open `index.html` in a browser, or publish it to GitHub Pages (served from the root of `main`).
