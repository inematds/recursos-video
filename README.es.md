# 🎬 Recursos de Video — ecosistema INEMA

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

Catálogo guía de todos los proyectos del ecosistema INEMA que **generan o procesan video**,
organizado por categoría, con lo que hace cada uno, cómo ejecutarlo y el enlace al repo.

Página única self-contained (`index.html`, estilo INEMA dark/ámbar): se abre en `file://`
o se publica directamente en GitHub Pages.

## Categorías

- **A · Renderizado determinístico** — pixflow, inemaref, HyperFrames, Remotion, mcp-video
- **B · Generación por IA** — VideosDGX2 (Wan 2.2), HuMo, skyreelsv3, Open-Generative-AI, seedance2
- **C · Dirección, plan y prompt** — mdd, diretor-animacao, video-plan-editor, promptprof, fontefilm
- **D · Orquestadores de punta a punta** — skill-videoprodutor, video-explicativo, video-demonstrativo, videos-cursos-inema, mkivideos, timesmkt3
- **E · Soporte (voz e imagen)** — inemavox, inemavox2, chatterbox, inemaimg, Kokoro
- **F · Doblaje y posproducción** — dublar5, video-use, upscayl

## Ver

Abra `index.html` en el navegador o publíquelo en GitHub Pages (se sirve desde la raíz de `main`).
