# 🎬 Recursos de Vídeo — ecossistema INEMA

**🇧🇷 [Português](README.md) · 🇺🇸 [English](README.en.md) · 🇪🇸 [Español](README.es.md)**

Catálogo-guia de todos os projetos do ecossistema INEMA que **geram ou processam vídeo**,
organizado por categoria, com o que cada um faz, como rodar e o link do repo.

Página única self-contained (`index.html`, padrão INEMA dark/âmbar) — abre em `file://`
ou publica direto no GitHub Pages.

## Categorias

- **A · Render determinístico** — pixflow, inemaref, HyperFrames, Remotion, mcp-video
- **B · Geração por IA** — VideosDGX2 (Wan 2.2), HuMo, skyreelsv3, Open-Generative-AI, seedance2
- **C · Direção, plano & prompt** — mdd, diretor-animacao, video-plan-editor, promptprof, fontefilm
- **D · Orquestradores ponta-a-ponta** — skill-videoprodutor, video-explicativo, video-demonstrativo, videos-cursos-inema, mkivideos, timesmkt3
- **E · Suporte (voz & imagem)** — inemavox, inemavox2, chatterbox, inemaimg, Kokoro
- **F · Dublagem & pós** — dublar5, video-use, upscayl

## Ver

Abra `index.html` no navegador, ou publique no GitHub Pages (serve da raiz da `main`).
