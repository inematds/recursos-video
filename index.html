O que é

Um catálogo, não um produto único

Esta página reúne ferramentas que evoluíram em paralelo. A ideia é parar de redescobrir “qual projeto faz X”: aqui você acha o caminho certo em segundos e vai direto pro guia.

🧭 7 caminhos

Determinístico, IA na nuvem, IA local, imagem, direção, orquestração e pós. Cada pedido de vídeo cai em um deles.

🏠 Local-first

A maioria roda na sua máquina/DGX: flux2-klein (imagem), inemavox (voz), HyperFrames/Remotion/pixflow (render). IA de vídeo local é opcional.

🔗 Tudo conectado

Os orquestradores reusam os mesmos tijolos — direção do MDD, imagem do inemaimg, voz do inemavox, render do HyperFrames.

funcional WIP / protótipo vazio / legado
Olhar antes de inventar

O que já funcionou de verdade

Antes de escrever pipeline novo, veja o que já foi medido. Estes cinco resolveram o problema e deixaram notas — inclusive dos defeitos.

videos-agnes — história → filme narrado, US$ 0

Padrão-ouro para conto animado: âncoras de personagem derivadas (não geradas em paralelo), descrição do personagem repetida em toda cena, narração por parágrafo, sem texto na tela. Saídas em ~/projetos/output/videos-agnes/.

agnesfree / agnes-nei — a API Agnes medida em ~70 chamadas

NOTAS-API.md traz as regras que valem dinheiro, os defeitos do modelo e os rate limits. Inclui a armadilha do filtro: personagem criança devolve HTTP 400 de forma determinística.

klingaimcp + klingai-nei — Kling com assinatura própria

Acesso via MCP e CLI, com conta, defaults e dublagem com voz clonada. Notas de API medidas em ~/projetos/wifi/KLING-NOTAS-API-2026-08-02.md.

pixflow — filme a partir de imagem estática, sem IA de vídeo

Parallax 2.5D com profundidade real, grain, LUT e vinheta. Determinístico: mesma entrada, mesmo resultado — o oposto do gerador de vídeo.

inemaref — fábrica de conteúdo a partir de uma referência

Um mesmo personagem atravessa folder, quadrinho, motion comic e série inteira, mantendo consistência visual.

Como escolher o caminho

Do pedido ao recurso certo

Comece pelo tipo de vídeo que você quer. O fluxo abaixo aponta o caminho; o catálogo tem o detalhe de cada peça.

Assunto / link / imagens→ Escolher caminho→ Direção / plano→ Imagem + voz→ Render→ MP4

🎞️ Quero algo reproduzível, sem IA de vídeo

Câmera/parallax sobre imagens, motion graphics, HQ animada. → pixflow, inemafilme, inemaref, HyperFrames, Remotion.

📖 Tenho uma história e quero o filme

Conto, episódio, personagem consistente. → videos-agnes (simples, US$ 0) ou videoanima (com decupagem e provedor trocável).

🤖 Quero movimento gerado por IA

Na nuvem/assinatura: klingaimcp, seedance2. Local na GPU: VideosDGX2 (Wan 2.2), HuMo, skyreelsv3.

🗣️ Quero alguém falando na tela

Avatar falante de roteiro. → heygenmcp (créditos da assinatura), videosavatar, ou HuMo pra lip-sync local.

🎬 Quero do assunto/link ao vídeo, automático

Explicativo, demo de app, videoaula, reels de marketing. → videoprodutor, video-explicativo, video-demonstrativo, videos-cursos-inema, timesmkt3.

✂️ Já tenho um vídeo e quero tratar

Dublar, cortar fillers, legendar, trocar a trilha. → dublar pro, inemavox, musicaclone, inemadlp.

Filme cinematográfico a partir de imagens estáticas: parallax com profundidade real + grain/LUT/vinheta/bloom, câmera e transições.

inemaref

Fábrica narrativa: folder de personagem → quadrinho → motion-comic e série inteira a partir de um assunto.

Motor base de quase todas as skills: anima HTML+GSAP e grava via Chrome headless. cchyperframes = editor.

scroll-film-studio

Pré-requisitos

O que precisa estar no ar

Os caminhos local-first dependem de alguns serviços e binários. Suba o que o seu caminho usa.

🖼️ inemaimg (imagem)

Servidor flux2-klein e cia.

# sobe o server de imagem
cd ~/projetos/inemaimg
docker compose up # :8000

🎙️ inemavox (voz)

Narração / clonagem / SFX.

# daemon de voz
cd ~/projetos/inemavox
uvicorn app:api # :8010

🧰 Base de render

Node + FFmpeg + Chrome (HyperFrames).

# checagem rápida
node -v && ffmpeg -version
echo $CHROMIUM_BIN
Guia rápido · do assunto ao vídeo

Um caminho típico (explicativo/produtor)

Exemplo do trajeto mais comum: um assunto vira vídeo profissional reusando os tijolos. Troque a skill conforme o tipo (explicativo, demo, série, marketing).

1

Suba imagem e voz

Os orquestradores chamam esses serviços; deixe-os no ar.

cd ~/projetos/inemaimg && docker compose up -d   # imagem :8000
cd ~/projetos/inemavox && uvicorn app:api &        # voz :8010
2

Escolha o caminho no catálogo

Explicativo → video-explicativo. Demo de app → video-demonstrativo. Pro/landing → videoprodutor. História → videos-agnes ou videoanima. Série/HQ → inemaref.

# cada skill responde a help
/video-explicativo "o que é engenharia de contexto"
3

Valide antes de gastar

Nos caminhos com provedor pago, confira ritmo e custo antes da primeira chamada.

python3 rodar.py exemplo --so-decupagem   # videoanima: valida sem gerar
4

Deixe a fila renderizar

Para lotes, enfileire no mkivideos e siga a vida — ele serializa a GPU e avisa no fim.

/mkivideos explicativo "tema"   # enfileira e renderiza em background
5

Pegue o MP4

A saída cai na pasta de output padrão; mova o final pro destino.

ls ~/projetos/output/<projeto>/   # mp4 16:9 e/ou 9:16
Consolidação

Canônicos, duplicados & limpeza

Vários projetos têm variantes. Use os canônicos; arquive ou remova o resto.

Voz
inemavox (GPU) + inemavox2 (CPU)Canônicos. ivox2 é só pesquisa — descartável.
IA vídeo
skyreelsv3 · HuMo · VideosDGX2Vazios/legado a limpar: skyreels, humo2, HuMo_clean, HuMo_velho. VideosDGX é a geração anterior do DGX2.
História
videos-agnes (simples) + videoanima (com direção)Não são o mesmo caminho: o primeiro é Agnes-only e direto; o segundo tem decupagem, keyframes A/B e provedor trocável. videosanimados e mkvideos são motores mais antigos da mesma família.
Dublagem
dublar pro (dublarv5)dublar, dublar2, dublar4 são versões antigas.
Marketing
timesmkt3timesmkt/timesmkt2 superados; imkt4 duplicado; imkt5 = nova arquitetura (ainda sem gerador de vídeo).
